Welcome to my repository!  

First of all, Vox (VoxCompiler) is a high-performance programming language designed for game development!  
Although Vox is oriented toward games, it is also very good at data processing! Vox has built-in data processing modules for `json`, `ini`, `yaml`, `toml`, `csv`, and `xml`! (Since V1.3.0)
It can also be used to build CLIs (using argparse, V1.3.0)!  
Despite its high performance, the syntax is not difficult at all!  
For details, see the `Documentation` folder in the repository!
[Click here to jump quickly](基础语法.md)
